# Guía para el documento de Fase 1

Estructura de apoyo para completar con análisis e ideas propias del alumno. No es un documento terminado ni contiene una reflexión personal inventada.

## Portada e índice
Completar institución, nombre completo, carrera, materia, proyecto y cuatrimestre. Preparar índice automático con números de página.

## 1. Definición del problema
Explica qué dificultades encontraste al buscar opciones de reciclaje; describe cómo buscaste información, qué fuentes contrastaste y a quién ayudaría el portal. Distingue observaciones propias de suposiciones.

## 2. Propuesta inicial
Describe el funcionamiento que propones. Consulta `acerca.php` para contrastar lo implementado con los roles conceptuales de visitante, usuario y editor. Justifica funcionalidades principales, complementarias y lo que queda fuera del alcance.

## 3. Requerimientos
Redacta al menos seis requerimientos funcionales indicando acción, usuario y respuesta esperada. Comprueba en el portal consulta, filtrado, detalle, guía, validación y resumen de aportación.

Documenta las reglas implementadas en `includes/functions.php`. Formula al menos cuatro requisitos no funcionales con criterios observables: presentación adaptable, navegación por teclado, reutilización de código y funcionamiento sin JavaScript son aspectos que puedes evaluar.

## 4. Diseño y navegación
Mapa implementado:

Inicio → Directorio → Detalle → Materiales

Inicio → Guía → Materiales → Directorio

Navegación → Participar → Confirmación o errores

Pie de página → Acerca del proyecto

Inserta capturas legibles de las pantallas ejecutadas en Apache y explica la función de cada una. Incluye filtro con resultados, búsqueda sin coincidencias, errores del formulario y confirmación de aportación. Evita capturar datos personales reales.

## 5. Desarrollo
Usa el README y la matriz técnica para describir las etapas de requisitos. No presentes las versiones como entregas históricas si no existieron. Explica decisiones que comprendas: Astro compila presentación, PHP consulta arreglos y valida, require reutiliza piezas comunes.

## 6. Conclusiones
Completa con tus propios aprendizajes y retos. Identifica qué puedes explicar del código, qué modificarías y cómo comprobarías la siguiente fase con base de datos.

## Formato y entrega
Arial 11 o 12, interlineado 1.15 o 1.5, márgenes de 2.5 cm, títulos jerarquizados y numeración de páginas. Exportar a PDF y nombrar con apellido y nombre del alumno según las indicaciones del curso.
