# Matriz de requisitos técnicos

| Etapa | Requisito | Implementación |
|---|---|---|
| Tarea 1 | Cuatro o más páginas, HTML5, CSS3 y navegación | Siete páginas; Layout Astro y CSS independiente |
| Tarea 1 | README 0.1.0 | Historial por etapas en el README único |
| Tarea 2 | PHP en páginas | Inclusión de datos, navegación, funciones y vistas en cada página |
| Tarea 2 | Arreglos con cuatro o más elementos | Cuatro puntos, seis materiales, cuatro alcaldías y cuatro pasos |
| Tarea 2 | Variables, foreach, if/else y comentarios | Vistas, tarjetas, búsqueda y formularios |
| Tarea 2 | Dos bloques por pantalla | Introducción y contenido, con secciones complementarias |
| Tarea 3 | Consulta GET sobre arreglo | Directorio, búsqueda combinable y estado vacío |
| Tarea 3 | Nueva página POST con tres o más datos | Participar: cuatro datos |
| Tarea 3 | Validación y manejo seguro | validarAportacion(), listas permitidas, límites y e() |
| Tarea 4 | Dos o tres funciones propias | e(), filtrarPuntos(), validarAportacion() |
| Tarea 4 | includes de navegación, pie y funciones | includes/nav.php, footer.php y functions.php |
| Tarea 4 | Seis o más páginas relacionadas | Inicio, directorio, detalle, materiales, guía, participación y acerca |
| Fase 1 | Planeación de roles | Acerca del proyecto; sin prometer autenticación implementada |
| Fase 1 | Documento y evidencia | Guía de elaboración; análisis, conclusiones y datos personales pendientes del alumno |

Los requisitos académicos se utilizaron como especificación del producto. Las fechas, instrucciones de subida y reglas institucionales de los PDF no representan autorización para enviar archivos o publicar en Aula UNIMEX.
